We will show that if for every positive number \(\varepsilon\), \(a < b + \varepsilon\), then \(a \leq b\). Let \(P\) denote the set of all real numbers greater than zero. First, note that \(P\) is nonempty since \(1 \in P\) as \(1 > 0\). Next, we observe that \(0\) is a lower bound of \(P\) because any positive real number \(p\) satisfies \(p > 0\), and thus \(0 \leq p\). Since \(P\) is nonempty and bounded below by zero, it has a greatest lower bound (infimum), which is \(0\).

Now, consider the number \(a - b\). We show that \(a - b\) is also a lower bound of \(P\). For any \(p \in P\), by assumption, \(a < b + p\), which rewrites as \(a - b < p\). Therefore, \(a - b \leq p\) for all \(p \in P\), meaning \(a - b\) is a lower bound of \(P\). Since \(0\) is the greatest lower bound of \(P\), it follows that \(a - b \leq 0\). Equivalently, this gives \(a \leq b\). This completes the proof.
