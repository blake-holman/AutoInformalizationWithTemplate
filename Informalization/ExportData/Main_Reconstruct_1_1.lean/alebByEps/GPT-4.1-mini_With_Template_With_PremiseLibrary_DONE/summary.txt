We will show that if for every positive number \(\varepsilon\), the inequality \(a < b + \varepsilon\) holds, then it follows that \(a \leq b\). Let \(P\) denote the set of all positive real numbers. First, we establish that this set is nonempty by noting that \(1 \in P\) since \(1 > 0\). Next, we observe that 0 is a lower bound of \(P\) because every element of \(P\) is strictly greater than zero and thus certainly greater than or equal to zero. Since \(P\) is nonempty and bounded below by 0, it has a greatest lower bound (infimum), denoted \(\inf P = 0\).

Now, consider \(a - b\). For any positive \(p \in P\), the assumption \(a < b + p\) can be rewritten as \(a - b < p\). If there existed \(p < a - b\), then adding \(b\) to both sides would yield \(b + p < a\), contradicting the earlier inequality. Hence, no \(p \in P\) is less than \(a - b\), so \(a - b\) is a lower bound of \(P\). Since \(\inf P = 0\) is the greatest lower bound, it follows that \(a - b \leq 0\). Rearranging this inequality gives \(a \leq b\), completing the proof.
