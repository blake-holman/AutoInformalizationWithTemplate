We will show that for any real number \( x \) and any positive real number \( \varepsilon \), there exists a rational number \( q \) such that the distance between \( x \) and \( q \) is less than \( \varepsilon \). To do this, we consider three cases based on the sign of \( x \).

First, if \( x > 0 \), we use the Archimedean property to find a natural number \( n \) such that \( \frac{1}{n+1} < \varepsilon \) and a natural number \( m \) such that \( \frac{m+1}{n+1} > x \). Defining the set \( M = \{ m \in \mathbb{N} : \frac{m+1}{n+1} > x \} \), we choose the minimal \( m \) in \( M \) and set \( q = \frac{m+1}{n+1} \). By analyzing the inequalities and considering the minimality of \( m \), we show that \( q - x \leq \frac{1}{n+1} < \varepsilon \), establishing that \( q \) approximates \( x \) within \( \varepsilon \). 

Next, if \( x = 0 \), the rational number \( q = 0 \) trivially satisfies \( |x - q| = 0 < \varepsilon \), confirming the result in this case.

Finally, if \( x < 0 \), then \(-x > 0\), so by the previous case, there exists a rational \( q \) such that \( |-x - q| < \varepsilon \). Setting \( q' = -q \), we find that \( |x - q'| = |x + q| = |-x - q| < \varepsilon \), so \( q' \) approximates \( x \) within \( \varepsilon \).

Combining these cases, we conclude that for any real number \( x \) and any \( \varepsilon > 0 \), there exists a rational number \( q \) such that \( |x - q| < \varepsilon \), which confirms the density of the rationals in the real numbers.
