We will show that for any real number \( x \) and any positive real number \( \varepsilon \), there exists a rational number \( q \) such that the distance between \( x \) and \( q \) is less than \( \varepsilon \). We proceed by cases based on the sign of \( x \).

First, if \( x > 0 \), by the Archimedean property, there exists a natural number \( n \) such that \( \frac{1}{n+1} < \varepsilon \). Next, again by the Archimedean property, there exists a natural number \( m \) such that \( \frac{m+1}{n+1} > x \). Define the set \( M = \{ m \in \mathbb{N} : \frac{m+1}{n+1} > x \} \), which is non-empty. Let \( m \) be the minimal element of \( M \), and set \( q = \frac{m+1}{n+1} \). Since \( q > x \), it suffices to show \( q - x < \varepsilon \). We know \( \frac{1}{n+1} < \varepsilon \), so it suffices to prove \( q - x \leq \frac{1}{n+1} \). Notice that \( q - \frac{1}{n+1} = \frac{m}{n+1} \), so we need to show \( \frac{m}{n+1} \leq x \). Suppose, for contradiction, that \( \frac{m}{n+1} > x \). If \( m \geq 1 \), then \( \frac{(m-1)+1}{n+1} > x \), implying \( m-1 \in M \), contradicting the minimality of \( m \). If \( m = 0 \), then \( x < 0 \), contradicting \( x > 0 \). Hence, \( \frac{m}{n+1} \leq x \), and thus \( |x - q| < \varepsilon \).

If \( x = 0 \), then choosing \( q = 0 \) yields \( |x - q| = 0 < \varepsilon \), so the statement holds trivially.

Finally, if \( x < 0 \), consider \(-x > 0\) and apply the above argument to find a rational \( q \) such that \( | -x - q | < \varepsilon \). Then \( |-x - q| = |x + q| < \varepsilon \), so \( |x - (-q)| < \varepsilon \). Since \(-q\) is rational, this establishes the statement for negative \( x \).

In all cases, we have shown that for any real number \( x \) and any positive \( \varepsilon \), there exists a rational number \( q \) such that \( |x - q| < \varepsilon \), completing the proof.
