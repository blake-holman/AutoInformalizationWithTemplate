We will show that for any real number \( x \) and any positive real number \( \varepsilon \), there exists a rational number \( q \) such that the distance between \( x \) and \( q \) is less than \( \varepsilon \). To this end, we consider three cases according to the sign of \( x \).

First, if \( x = 0 \), choosing \( q = 0 \) immediately yields \(|0 - q| = 0 < \varepsilon\), satisfying the requirement.

Second, if \( x > 0 \), we use the Archimedean property. Given \( \varepsilon > 0 \), select a natural number \( n \) such that \(\frac{1}{n+1} < \varepsilon\). By Archimedean property, there exists a natural number \( m \) with \(\frac{m+1}{n+1} > x\). Defining the set \( M \) as all natural numbers \( m \) for which this holds, \( M \) is nonempty, and we take its minimal element \( m \). Setting \( q = \frac{m+1}{n+1} \), we have \( q > x \). To show \(|x - q| < \varepsilon\), note that this reduces to proving \( q - x \leq \frac{1}{n+1} < \varepsilon \). Suppose for contradiction that \( \frac{m}{n+1} > x \). If \( m \geq 1 \), then \( m - 1 \in M \), contradicting the minimality of \( m \). If \( m = 0 \), then \( x < 0 \), contradicting \( x > 0 \). Hence, \( \frac{m}{n+1} \leq x \), and so \(|x - q| = q - x \leq \frac{1}{n+1} < \varepsilon\).

Third, if \( x < 0 \), then \(-x > 0\). By the previous case, there exists a rational number \( q \) such that \(|-x - q| < \varepsilon\). Setting \( q' = -q \), we find \(|x - q'| = |x + q| = |-x - q| < \varepsilon\), providing the required rational approximation.

Combining these cases, we conclude that for every real number \( x \) and every positive real number \( \varepsilon \), there exists a rational number \( q \) such that \(|x - q| < \varepsilon\), establishing the density of the rationals in the real numbers.
