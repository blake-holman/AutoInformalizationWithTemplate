We will show that a real number \(a_0\) is the supremum of a nonempty set \(A\) bounded above if and only if it is an upper bound of \(A\) and every neighborhood immediately below it contains an element of \(A\). First, suppose that \(a_0 = \sup A\). By definition, \(a_0\) is an upper bound of \(A\), so every element \(a \in A\) satisfies \(a \leq a_0\). Now, assume for contradiction that there exists some \(\varepsilon > 0\) such that no element of \(A\) exceeds \(a_0 - \varepsilon\). Then \(a_0 - \varepsilon\) would be an upper bound of \(A\) smaller than \(a_0\), contradicting the minimality of \(a_0\). Hence, for every \(\varepsilon > 0\), there is an element \(a \in A\) with \(a > a_0 - \varepsilon\). Conversely, suppose \(a_0\) is an upper bound of \(A\) and for every \(\varepsilon > 0\), there exists \(a \in A\) such that \(a > a_0 - \varepsilon\). Then, for any upper bound \(x\) of \(A\), if \(x < a_0\), setting \(\varepsilon = a_0 - x > 0\) implies the existence of an \(a \in A\) with \(a > x\), contradicting that \(x\) is an upper bound. Therefore, \(a_0 \leq x\) for any upper bound \(x\), showing that \(a_0\) is the least upper bound, i.e., the supremum of \(A\). This completes the proof.
