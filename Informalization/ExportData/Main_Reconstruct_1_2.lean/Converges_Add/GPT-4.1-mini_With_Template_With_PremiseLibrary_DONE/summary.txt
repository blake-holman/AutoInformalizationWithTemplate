We will show that if two sequences \((x_n)\) and \((y_n)\) converge to real numbers \(a\) and \(b\), respectively, then the sequence formed by their term-wise sums \((x_n + y_n)\) converges to \(a + b\). Let \(\varepsilon > 0\) be given. Since \((x_n)\) converges to \(a\), there exists an index \(n_1\) such that for all \(n \geq n_1\), \(|x_n - a| < \frac{\varepsilon}{2}\). Similarly, because \((y_n)\) converges to \(b\), there exists an index \(n_2\) such that for all \(n \geq n_2\), \(|y_n - b| < \frac{\varepsilon}{2}\). Setting \(n_0 = \max(n_1, n_2)\), it follows that for all \(n \geq n_0\), both inequalities hold simultaneously. Applying the triangle inequality, we deduce
\[
|x_n + y_n - (a + b)| = |(x_n - a) + (y_n - b)| \leq |x_n - a| + |y_n - b| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
\]
Hence, the sequence \((x_n + y_n)\) converges to \(a + b\), completing the proof.
