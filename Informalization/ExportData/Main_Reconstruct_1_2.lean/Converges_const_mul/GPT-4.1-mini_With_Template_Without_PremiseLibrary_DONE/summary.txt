We will show that if a sequence \((x_n)\) converges to a limit \(a\), then the sequence obtained by multiplying each term by a real number \(\alpha\) converges to \(\alpha a\). Let \(\varepsilon > 0\) be given. Since \((x_n)\) converges to \(a\), there exists a natural number \(n_0\) such that for all \(n \geq n_0\), we have \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\). Note that \(|\alpha| + 1 > 0\), ensuring the fraction is well-defined. For any \(n \geq n_0\), we consider the absolute value \(|\alpha x_n - \alpha a| = |\alpha||x_n - a|\). If \(|\alpha| > 0\), multiplying the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) by \(|\alpha|\) yields \(|\alpha x_n - \alpha a| < \frac{|\alpha| \varepsilon}{|\alpha| + 1}\). Since \(\frac{|\alpha|}{|\alpha| + 1} < 1\), it follows that \(|\alpha x_n - \alpha a| < \varepsilon\). If \(|\alpha| = 0\), then \(\alpha = 0\) and \(|\alpha x_n - \alpha a| = 0 < \varepsilon\) trivially holds. Thus, in all cases, there exists \(n_0\) such that for all \(n \geq n_0\), \(|\alpha x_n - \alpha a| < \varepsilon\), which establishes that the sequence \((\alpha x_n)\) converges to \(\alpha a\). This completes the proof using the theorem that the limit of a constant multiple of a convergent sequence equals the constant multiplied by the limit of the sequence.
