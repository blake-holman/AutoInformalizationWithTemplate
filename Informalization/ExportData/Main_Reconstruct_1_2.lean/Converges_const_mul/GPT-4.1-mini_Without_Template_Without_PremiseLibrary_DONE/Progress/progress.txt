Assume an arbitrary positive tolerance \(\varepsilon > 0\). Since \( x_n \to a \), there exists a natural number \( n_0 \) such that for all \( n \geq n_0 \), the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) holds. Note that \(|\alpha| + 1 > 0\), ensuring the denominator is positive.

Now, for any \( n \geq n_0 \), consider the absolute difference \(|\alpha x_n - \alpha a|\). By factoring out \(\alpha\) and using the multiplicative property of absolute values, we have \(|\alpha x_n - \alpha a| = |\alpha||x_n - a|\). Using the previous bound on \(|x_n - a|\), this is less than \(|\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1} = \frac{|\alpha|\varepsilon}{|\alpha| + 1} \).

We distinguish two cases: if \(|\alpha| > 0\), dividing both sides of the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) by \(|\alpha|\) preserves the inequality, so it follows that \(|\alpha||x_n - a| < \varepsilon\), yielding \(|\alpha x_n - \alpha a| < \varepsilon\). If \(|\alpha| = 0\), then \(\alpha = 0\) and both \(|\alpha x_n - \alpha a|\) and \(\varepsilon\) are nonnegative, making the inequality hold trivially.

Thus, in every case, for all \( n \geq n_0 \) we have \(|\alpha x_n - \alpha a| < \varepsilon\), confirming that the sequence \( (\alpha x_n) \) converges to \(\alpha a\) as claimed.
