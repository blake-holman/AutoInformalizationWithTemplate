We will show that if a sequence \((x_n)\) converges to a real number \(a\), then the sequence obtained by multiplying each term by a real constant \(\alpha\) converges to \(\alpha a\). Assume \(\varepsilon > 0\) is given. Since \(\lim_{n \to \infty} x_n = a\), there exists \(n_0 \in \mathbb{N}\) such that for all \(n \geq n_0\), \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\). Note that \(|\alpha| + 1 > 0\), so this expression is well-defined. For these \(n\), we consider \(|\alpha x_n - \alpha a| = |\alpha| \cdot |x_n - a|\). When \(|\alpha| > 0\), multiplying the inequality by \(|\alpha|\) preserves it, yielding \(|\alpha x_n - \alpha a| < |\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1} < \varepsilon\), since \(|\alpha| < |\alpha| + 1\). If \(\alpha = 0\), then the difference is zero, which is trivially less than \(\varepsilon\). Thus, in both cases, for all \(n \geq n_0\), \(|\alpha x_n - \alpha a| < \varepsilon\), establishing that \(\alpha x_n \to \alpha a\) by the definition of convergence. This completes the proof.
