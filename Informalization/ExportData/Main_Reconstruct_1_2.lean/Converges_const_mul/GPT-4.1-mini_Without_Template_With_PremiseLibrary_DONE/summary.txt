We will show that if a sequence \((x_n)\) converges to a limit \(a\), then the sequence obtained by multiplying each term by a constant \(\alpha\) converges to \(\alpha a\). Assume that \((x_n)\) converges to \(a\). Let \(\varepsilon > 0\) be arbitrary. By the definition of convergence, there exists \(n_0 \in \mathbb{N}\) such that for all \(n \geq n_0\), \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\). Consider the absolute difference \(|\alpha x_n - \alpha a|\), which can be rewritten as \(|\alpha||x_n - a|\) by the multiplicative property of absolute values. If \(|\alpha| > 0\), then \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1} < \frac{\varepsilon}{|\alpha|}\), so multiplying both sides by \(|\alpha|\) yields \(|\alpha||x_n - a| < \varepsilon\). If \(\alpha = 0\), then \(|\alpha x_n - \alpha a| = 0 < \varepsilon\) trivially. Therefore, in all cases, for all \(n \geq n_0\), we have \(|\alpha x_n - \alpha a| < \varepsilon\), which establishes that the sequence \((\alpha x_n)\) converges to \(\alpha a\). This completes the proof.
