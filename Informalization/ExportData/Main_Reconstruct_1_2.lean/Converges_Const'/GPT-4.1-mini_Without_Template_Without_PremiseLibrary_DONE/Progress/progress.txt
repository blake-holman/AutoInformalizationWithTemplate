[applied Tactic]
have : |(fun _ => a) n - a| = 0 := by
    rw [sub_self,abs_zero ] 

[answer]
We will show that the absolute value of the difference between the constant function evaluated at \( n \) and the constant \( a \) is zero. To do this, we observe that subtracting \( a \) from itself yields zero, so the expression simplifies to the absolute value of zero. Since the absolute value of zero is zero, it follows directly that the original expression equals zero, completing the proof.
