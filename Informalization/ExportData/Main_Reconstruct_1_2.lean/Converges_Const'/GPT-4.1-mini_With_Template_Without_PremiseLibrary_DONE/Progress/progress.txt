[applied Tactic]
have : |(fun _ => a) n - a| = 0 := by
    rw [sub_self,abs_zero ] 

[answer]
We will show that the absolute value of the difference between the constant function evaluated at \( n \) and \( a \) is equal to zero. Since the constant function takes the same value \( a \) for any input \( n \), the difference \(|f(n) - a|\) simplifies to \(|a - a|\). Recognizing that subtracting a quantity from itself yields zero, we have \(|a - a| = 0\). Furthermore, the absolute value of zero is zero, which completes the proof.
