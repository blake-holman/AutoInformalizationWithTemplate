[applied Tactic]
have : |(fun _ => a) n - a| = 0 := by
    rw [sub_self,abs_zero ] 

[answer]
We will show that the absolute value of the difference between the constant function evaluated at \( n \) and \( a \) is zero. Since the constant function always outputs \( a \), evaluating it at \( n \) yields \( a \). Therefore, the difference between the constant function evaluated at \( n \) and \( a \) is \( a - a \), which equals zero. Taking the absolute value of zero gives zero, hence the absolute value of the difference is zero as required.
