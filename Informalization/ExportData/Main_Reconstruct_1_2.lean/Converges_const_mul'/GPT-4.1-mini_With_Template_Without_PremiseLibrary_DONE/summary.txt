We will show that if a sequence \((x_n)\) converges to a limit \(a\), then the sequence \((\alpha x_n)\), obtained by multiplying each term of \((x_n)\) by a fixed scalar \(\alpha\), converges to \(\alpha a\). Let \(\varepsilon > 0\) be given. Since \((x_n)\) converges to \(a\), there exists a natural number \(n_0\) such that for all \(n \geq n_0\), the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) holds. Note that the denominator \(|\alpha| + 1\) is positive, ensuring this choice is valid. For any \(n \geq n_0\), consider the absolute value \(|\alpha x_n - \alpha a|\). By properties of absolute value, this equals \(|\alpha| \cdot |x_n - a|\). We examine two cases: if \(|\alpha| > 0\), then multiplication by the positive number \(|\alpha|\) preserves inequality, so \(|\alpha x_n - \alpha a| \leq |\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1}\). Since \(|\alpha| < |\alpha| + 1\), it follows that this product is less than \(\varepsilon\). If \(|\alpha| = 0\), then \(\alpha = 0\), and \(|\alpha x_n - \alpha a| = 0 < \varepsilon\) trivially. Thus, for all \(n \geq n_0\), we have \(|\alpha x_n - \alpha a| < \varepsilon\), which establishes that the sequence \((\alpha x_n)\) converges to \(\alpha a\) as required.
