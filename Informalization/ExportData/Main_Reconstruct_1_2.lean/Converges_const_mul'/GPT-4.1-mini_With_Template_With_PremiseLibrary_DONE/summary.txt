We will show that if a sequence \( (x_n) \) converges to \( a \), then the sequence \( (\alpha x_n) \), obtained by multiplying each term by a constant \(\alpha\), converges to \(\alpha a\). Let \(\varepsilon > 0\) be arbitrary. Since \( (x_n) \) converges to \( a \), there exists a natural number \( n_0 \) such that for all \( n \geq n_0 \), the inequality \( |x_n - a| < \frac{\varepsilon}{|\alpha| + 1} \) holds. Note that the denominator \( |\alpha| + 1 \) is positive, ensuring the bound is well-defined. Now, for all \( n \geq n_0 \), observe that
\[
|\alpha x_n - \alpha a| = |\alpha||x_n - a|.
\]
If \( |\alpha| > 0 \), then multiplying the inequality \( |x_n - a| < \frac{\varepsilon}{|\alpha| + 1} \) by \( |\alpha| \) preserves the inequality, yielding
\[
|\alpha||x_n - a| < \frac{|\alpha|\varepsilon}{|\alpha| + 1} < \varepsilon,
\]
since \( |\alpha| < |\alpha| + 1 \). On the other hand, if \( |\alpha| = 0 \), then \(\alpha = 0\) and the inequality trivially holds because \( |\alpha x_n - \alpha a| = 0 < \varepsilon \). Thus, in all cases, for \( n \geq n_0 \), we have \( |\alpha x_n - \alpha a| < \varepsilon \), which establishes that the sequence \( (\alpha x_n) \) converges to \(\alpha a\), as required.
