We will show that if a sequence \((x_n)\) converges to a limit \(a\), then for any scalar \(\alpha \in \mathbb{R}\), the sequence \((\alpha x_n)\) converges to \(\alpha a\). To this end, let \(\varepsilon > 0\) be arbitrary. Since \((x_n)\) converges to \(a\), by definition there exists a natural number \(n_0\) such that for all \(n \geq n_0\), the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) holds; note that this denominator is positive because \(|\alpha| + 1 > 0\). For such \(n\), consider the difference
\[
|\alpha x_n - \alpha a| = |\alpha| \cdot |x_n - a|.
\]
By our choice of \(n_0\), this is bounded above by
\[
|\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1} = \frac{|\alpha| \varepsilon}{|\alpha| + 1}.
\]
Since \(|\alpha| < |\alpha| + 1\), it follows that
\[
\frac{|\alpha| \varepsilon}{|\alpha| + 1} < \varepsilon,
\]
and thus
\[
|\alpha x_n - \alpha a| < \varepsilon.
\]

In the case \(\alpha = 0\), the sequence \((\alpha x_n)\) is identically zero, so the inequality trivially holds. Hence, in all cases, for every \(\varepsilon > 0\), there exists \(n_0\) such that for all \(n \geq n_0\), \(|\alpha x_n - \alpha a| < \varepsilon\), demonstrating that \((\alpha x_n)\) converges to \(\alpha a\). This completes the proof.
