We will show that if a sequence \((x_n)\) converges to a limit \(a\), then the sequence \((\alpha x_n)\), obtained by multiplying each term by a real number \(\alpha\), converges to \(\alpha a\). Let \(\varepsilon > 0\) be given. Since \((x_n)\) converges to \(a\), there exists a natural number \(n_0\) such that for all \(n \geq n_0\), the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) holds. Note that the denominator \( |\alpha| + 1 \) is strictly positive, ensuring the fraction is well-defined. Using the properties of absolute value and distributivity, we observe that
\[
|\alpha x_n - \alpha a| = |\alpha| \cdot |x_n - a|.
\]
If \(|\alpha| > 0\), multiplying both sides of the inequality \(|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}\) by the positive factor \(|\alpha|\) preserves the inequality:
\[
|\alpha x_n - \alpha a| < |\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1} < \varepsilon,
\]
where the last inequality follows from the elementary fact that \(|\alpha| < |\alpha| + 1\). In the case \(\alpha = 0\), the expression \(|\alpha x_n - \alpha a|\) reduces to zero, which is trivially less than any \(\varepsilon > 0\). Therefore, for all \(n \geq n_0\), we have \(|\alpha x_n - \alpha a| < \varepsilon\), proving that \((\alpha x_n)\) converges to \(\alpha a\), as required.
