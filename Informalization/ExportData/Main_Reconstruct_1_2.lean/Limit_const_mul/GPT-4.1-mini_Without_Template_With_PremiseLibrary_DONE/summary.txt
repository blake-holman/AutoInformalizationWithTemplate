We will show that if a sequence \((x_n)\) converges to a limit \(a\), then the sequence obtained by multiplying each term by a constant \(\alpha\) converges to \(\alpha a\). Assuming that \((x_n)\) converges to \(a\), let \(\varepsilon > 0\) be given arbitrarily. By the definition of convergence, there exists an index \(n_0\) such that for all \(n \geq n_0\), we have

\[
|x_n - a| < \frac{\varepsilon}{|\alpha| + 1}.
\]

Since the denominator \( |\alpha| + 1 \) is strictly positive, this expression is well-defined. For any \(n \geq n_0\), consider the absolute difference

\[
|\alpha x_n - \alpha a| = |\alpha| \cdot |x_n - a|.
\]

Using the above bound, we deduce

\[
|\alpha x_n - \alpha a| < |\alpha| \cdot \frac{\varepsilon}{|\alpha| + 1} = \frac{|\alpha| \varepsilon}{|\alpha| + 1}.
\]

Because \(\frac{|\alpha|}{|\alpha| + 1} < 1\), it follows that

\[
|\alpha x_n - \alpha a| < \varepsilon.
\]

In the case where \(|\alpha| = 0\), we have \(\alpha = 0\) and the sequence \((\alpha x_n)\) is identically zero, which trivially converges to \(0 = \alpha a\). Thus, in all cases, for every \(\varepsilon > 0\), there exists an index \(n_0\) such that for all \(n \geq n_0\),

\[
|\alpha x_n - \alpha a| < \varepsilon,
\]

showing that \((\alpha x_n)\) converges to \(\alpha a\). Finally, since limits of convergent sequences are unique, we conclude that the limit of the sequence \((\alpha x_n)\) equals \(\alpha\) times the limit of \((x_n)\), as required.
