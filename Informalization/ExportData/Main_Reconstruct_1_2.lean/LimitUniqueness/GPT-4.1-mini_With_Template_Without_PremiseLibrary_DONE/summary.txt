We will show that if a sequence \(x_n\) converges to both \(a\) and \(b\), then \(a = b\). To this end, let \(\varepsilon > 0\) be arbitrary. Since \(x_n \to a\), there exists \(n_1 \in \mathbb{N}\) such that for all \(n \geq n_1\), \(|x_n - a| < \frac{\varepsilon}{2}\). Similarly, since \(x_n \to b\), there exists \(n_2 \in \mathbb{N}\) such that for all \(n \geq n_2\), \(|x_n - b| < \frac{\varepsilon}{2}\). Setting \(n = \max(n_1, n_2)\), we have for all \(n \geq n\), both inequalities hold simultaneously. Using the triangle inequality, we note that \(|a - b| = |(a - x_n) + (x_n - b)| \leq |a - x_n| + |x_n - b| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon\). Since \(\varepsilon > 0\) was arbitrary, it follows that \(|a - b| = 0\), and hence by properties of absolute value, \(a = b\). This completes the proof.
