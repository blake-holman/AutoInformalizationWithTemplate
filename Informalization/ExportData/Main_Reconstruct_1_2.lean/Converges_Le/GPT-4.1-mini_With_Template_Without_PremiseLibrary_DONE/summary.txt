We will show that if two sequences \((x_n)\) and \((y_n)\) converge to limits \(a\) and \(b\) respectively, and if for every natural number \(n\), \(x_n \leq y_n\), then it follows that \(a \leq b\). Let \(\varepsilon > 0\) be arbitrary. By the definition of convergence, there exist indices \(n_1\) and \(n_2\) such that for all \(n \geq n_1\), \(|x_n - a| < \frac{\varepsilon}{2}\), and for all \(n \geq n_2\), \(|y_n - b| < \frac{\varepsilon}{2}\). Set \(n_0 = \max(n_1, n_2)\), so that for all \(n \geq n_0\), both inequalities hold simultaneously. From the bound on \(x_n\), we deduce \(a - \frac{\varepsilon}{2} < x_n\), and from the bound on \(y_n\), it follows that \(y_n < b + \frac{\varepsilon}{2}\). Since \(x_n \leq y_n\) by assumption, we have the chain of inequalities \(a - \frac{\varepsilon}{2} < x_n \leq y_n < b + \frac{\varepsilon}{2}\) for all \(n \geq n_0\). In particular, this holds at \(n = n_0\). By transitivity, it follows that \(a - \frac{\varepsilon}{2} < b + \frac{\varepsilon}{2}\), which can be rearranged using the properties of addition to yield \(a < b + \varepsilon\). Since \(\varepsilon > 0\) was arbitrary, we conclude that \(a \leq b\). Thus, the limit of the sequence \((x_n)\) is less than or equal to the limit of \((y_n)\), as required.
