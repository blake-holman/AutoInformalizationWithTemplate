have xnleyn : ∀n, x n ≤ y n := by
      intro n
      exact xnlea  n 

[answer]
We will show that for every natural number \( n \), the value of \( x(n) \) is less than or equal to the value of \( y(n) \). Let \( n \) be an arbitrary natural number. By the given assumption, for every natural number \( n \), \( x(n) \leq a \). Since this holds for all such \( n \), it follows directly that \( x(n) \leq y(n) \) for every natural number \( n \), completing the proof.
