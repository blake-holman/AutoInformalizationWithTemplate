We will show that if two sequences \((x_n)\) and \((y_n)\) satisfy \(x_n \leq y_n\) for every natural number \(n\), and if \((x_n)\) converges to \(a\) while \((y_n)\) converges to \(b\), then \(a \leq b\).

To prove this, fix an arbitrary positive number \(\varepsilon\) and show that \(a < b + \varepsilon\). Since \(\varepsilon > 0\), we use the convergence of the sequences to find indices \(n_1\) and \(n_2\) such that for all \(n \geq n_1\), \(|x_n - a| < \varepsilon/2\), and for all \(n \geq n_2\), \(|y_n - b| < \varepsilon/2\). Let \(n_0 = \max(n_1, n_2)\), so for all \(n \geq n_0\), these inequalities hold simultaneously.

For any \(n \geq n_0\), we establish the chain of inequalities:
\[
a - \frac{\varepsilon}{2} < x_n \leq y_n < b + \frac{\varepsilon}{2}.
\]
This follows since \(a - \varepsilon/2 < x_n\) by the convergence condition on \((x_n)\), and \(y_n < b + \varepsilon/2\) by the convergence condition on \((y_n)\), while the original assumption ensures \(x_n \leq y_n\).

Evaluating these inequalities at \(n = n_0\), it follows that
\[
a - \frac{\varepsilon}{2} < y_{n_0} < b + \frac{\varepsilon}{2},
\]
and by transitivity,
\[
a - \frac{\varepsilon}{2} < b + \frac{\varepsilon}{2}.
\]

Using the properties of addition and ordering, this inequality can be rewritten as
\[
a < b + \varepsilon.
\]

Since \(\varepsilon > 0\) was arbitrary, it follows from the standard squeeze-type argument that \(a \leq b\). This concludes the proof.
